# 🌈🦄 Rainbow Unicorn Tic-Tac-Toe 🦄🌈

A magical, whimsical Tic-Tac-Toe game with a rainbow unicorn theme! Play locally with two players.

## Features

- ✨ Beautiful rainbow gradient background with animated colors
- 🦄 Unicorn-themed icons (🦄 for Player X, ✨ for Player O)
- 🎨 Sparkly, colorful UI with smooth animations
- 📱 Fully responsive design (works on desktop and mobile)
- 🎯 Complete game logic with win/draw detection
- 🔄 Reset button to start a new game

## Setup & Installation

1. **Install Python dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Run the Flask server:**
   ```bash
   python app.py
   ```

3. **Open your browser:**
   Navigate to `http://localhost:5000`

## How to Play

1. Player 1 (🦄) goes first
2. Click on any empty cell to place your mark
3. Players alternate turns
4. First player to get 3 in a row (horizontal, vertical, or diagonal) wins!
5. If the board fills up with no winner, it's a draw
6. Click "🔄 Play Again" to start a new game
